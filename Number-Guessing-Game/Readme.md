# Number Guessing Game

A terminal-based guessing game built using C.

The computer generates a random number between 1 and 100, and the player tries to guess it using hints.

---

## How to Play

1. Run the program
2. Enter a number between 1 and 100
3. The game will guide you:
   - Too low!
   - Too high!
4. Keep guessing until you find the correct number
5. The total number of attempts will be displayed

---

## Example

```plaintext
=== Number Guessing Game ===

Enter your guess (1-100): 50
Too high!

Enter your guess (1-100): 20
Too low!

Enter your guess (1-100): 37
Correct! You won!

Attempts: 3
```
